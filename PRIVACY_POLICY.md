# Privacy Policy for GalleryMe

**Last updated:** January 2025

## Overview

GalleryMe is a browser extension that extracts and displays images and videos from webpages. Your privacy is important, and this extension is designed to respect it.

## Data Collection

**GalleryMe does not collect, store, or transmit any personal data.**

## What the Extension Does

- Scans the current webpage for images and videos when you click "Scan Page"
- Stores found media URLs locally in your browser's storage
- All data remains on your device and is never sent to any external server

## Permissions Used

| Permission | Why It's Needed |
|------------|-----------------|
| activeTab | To access the current page content when you initiate a scan |
| scripting | To inject the script that finds images and videos on the page |
| storage | To save found media locally so you can view it later |

## Data Storage

- Media URLs are stored locally using Chrome's storage API
- Data is stored per-website and remains on your device
- You can clear stored data anytime using the "Clear" button in the extension

## Third-Party Services

This extension does not use any third-party services, analytics, or tracking.

## Changes to This Policy

Any changes to this privacy policy will be reflected in this document with an updated date.
